# Codex Switch（Codex 切换助手）

> 一个软件，帮你管理 Codex 的"连接方式"：一键在 **ChatGPT 官方账户** 和 **各种 API 接口** 之间切换，会话记录永远不丢。

---

## 🎯 这个软件解决什么问题？

你有两种方式使用 Codex（AI 编程助手）：

1. **官方账户**：用你的 ChatGPT 登录账号（需要 Plus/Pro 订阅）
2. **API 接口**：买别人的 API（比如 DeepSeek、各种中转服务），用 Key 连接

问题来了：**切换很麻烦，还要改一堆配置文件**。这个软件就是帮你一键切换，还有"清缓存刷新"功能 —— 聊天列表乱了、模型不刷新了，点一下就修好。

**适合完全不懂电脑配置的人使用。** 全程点点鼠标，不用碰任何代码。

## 🚀 第二步：第一次打开（自动引导配置）

双击打开软件，会看到一个欢迎页，**按提示点就行**：

### 情况 A：你有 ChatGPT 官方账户（Plus/Pro 订阅）

1. 选择 **「ChatGPT 官方账户」**
2. 点 **「使用官方账户」**
3. 完成！软件会自动帮你设置好

### 情况 B：你用的是 API（别人给你的 Base URL 和 Key）

1. 选择 **「API 调用」** → 下一步
2. 填写三样东西（向给你 API 的人要）：
   - **Base URL**：接口地址，形如 `https://xxx.com`
   - **API Key**：一串密钥，形如 `sk-xxxxxx`
   - **默认模型 ID**：形如 `gpt-5.5`、`deepseek-chat`
3. 点 **「测试连接」** —— 显示"连接成功"就说明填对了
4. 点 **「完成并切换」**

> 🔒 你的 API Key 会**加密存进电脑的钥匙串/凭据管理器**，不会保存在配置文件里，也不会被上传到任何地方。

## 🖱 第三步：日常使用（三个功能）

打开软件，首页就是全部功能：

### 1️⃣ 一键切换
看到所有已配置的连接方式（Provider），点 **「切换」** 按钮即可。
- 当前正在用的会标着 **「当前」**
- 切换后 ChatGPT 会自动重启，稍等几秒

### 2️⃣ 清缓存刷新
聊天列表不显示、模型列表不对、界面奇怪时：
- 点 **「清缓存刷新」** —— 常规清理
- 点 **「深度清理」** —— 更彻底（会先备份，放心）

> 只清理缓存文件，**你的聊天记录永远安全**。

### 3️⃣ Provider 管理（添加更多 API）
首页 → 左侧 **「Provider 管理」** → 点 **「+ 添加 Provider」**，填上名称、Base URL、Key、模型即可。可以同时配置很多个，随时切换。

## ❓ 常见问题

**Q：切换后提示"模型容量满"（selected model is at capacity）？**
A：这是官方服务器高峰期忙。切换到另一个连接方式，或者过一会儿再试。

**Q：切换没反应 / 聊天列表不见了？**
A：点首页 **「清缓存刷新」**，等几秒。还是不行就重启一下 ChatGPT。

**Q：Key 填错了怎么办？**
A：到「Provider 管理」里点「编辑」，重新填 Key，保存即可。

**Q：这个软件安全吗？**
A：软件是开源的，代码全部公开。API Key 存在系统钥匙串里加密保存，配置文件里没有明文密钥。软件只修改 Codex 自己的配置文件（`~/.codex/`），不碰你的其他文件。

**Q：什么是 Base URL？什么是 API Key？**
A：Base URL 是"接口地址"（服务器在哪），API Key 是"通行证"（证明你有权限用）。找卖你 API 的人要这两个东西。
